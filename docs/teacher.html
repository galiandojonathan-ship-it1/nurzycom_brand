Результаты учеников

Сводка по ответам из Google Form: кто что сдал, где ошибки, что повторить на уроке. Данные открываются только в этом браузере: страница ничего не хранит на сервере и никуда их не отправляет.

Способ 1 · файл (рекомендую)
  1. Google Forms → вкладка Responses → View in Sheets.
  2. В таблице: File → Download → Comma Separated Values (.csv).
  3. Перетащите файл сюда или нажмите на поле.
Способ 2 · живая ссылка
  1. В таблице ответов: File → Share → Publish to web.
  2. Выберите лист Form Responses 1 и формат Comma-separated values (.csv) → Publish.
  3. Скопируйте ссылку и вставьте сюда. Она сохранится только в этом браузере.

Внимание: опубликованную таблицу может открыть любой, у кого есть ссылка. Не пересылайте её и не публикуйте.

Пароль сайта

Один пароль для всех учеников. После смены старый пароль перестаёт работать: ученики увидят окно входа и введут новый. Сайт начинает принимать новый пароль через 1–10 минут.

GitHub · подключить один раз
  1. GitHub → фото профиля → Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token.
  2. Token name: nurzycom password. Expiration: на ваш выбор (например, 1 year).
  3. Repository access → Only select repositories → выберите репозиторий сайта.
  4. Permissions → Repository permissions → Contents → Read and write.
  5. Generate token, скопируйте его и вставьте сюда. Токен хранится только в этом браузере.
