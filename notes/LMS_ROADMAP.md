# План развития study.bynurzy.com

1. **Урок идёт без пауз.** Преподаватель переключает занятие из пульта, ученик успевает ответить при слабой связи, а учебный материал открывается целиком.
2. **Ученик видит свой прогресс.** Практика помогает заметить ошибку в рассуждении, проверить себя на новой задаче и вспомнить приём через несколько дней.
3. **Преподаватель готовится и проверяет быстрее.** Платформа собирает доказательства из ответов, предлагает следующие действия, а преподаватель решает, что показать и назначить.

## Порядок работы

| Шаг | Что меняется в уроке | Первая версия | Как понять, что получилось |
| --- | --- | --- | --- |
| 1. Устойчивые ответы | В «Своём темпе» ученик отправляет один ответ и сразу переходит дальше. На каждом вопросе видно, что сохранилось и что нужно повторить. | Независимое сохранение разных вопросов, подтверждение и ошибки по каждому вопросу. | При задержке первого запроса решение второго всё равно попадает к преподавателю. При ошибке видно номер вопроса и можно повторить отправку. |
| 2. Материал слайда целиком | Преподаватель отправляет вопрос одним кликом, а ученику доступны график, таблица или подчёркнутый фрагмент, нужные для решения. | Поддержать график из упражнения V09 и подчёркивание из V06. Перед отправкой показать в пульте, если обязательный материал не перенёсся. | В двух известных примерах вопрос решается по экрану ученика на компьютере и телефоне. Ключ и заметки преподавателя доступны только учителю. |
| 3. Единый пульт на уроке | Из одной панели преподаватель запускает холодный старт, переключается на объяснение или практику, смотрит поступающие ответы и возвращается к слайду. Ученик входит по одной ссылке. | Очередь из выбранных слайдов и практик, кнопки «Назад» и «Дальше», восстановление текущего этапа после перезагрузки. | В тестовом уроке можно пройти четыре этапа без смены вкладки и вернуться к текущему этапу после обновления страницы. |
| 4. Момент для объяснения | Видно, что несколько учеников выбрали один ошибочный вариант. Преподаватель открывает именно этот вопрос и просит класс сравнить два варианта. | В таблицу раунда добавить показатели «ответили», «пропустили» и «самый частый неверный вариант» для выбранного вопроса. В режиме показа классу скрывать имена. | По таблице можно выбрать вопрос для разбора, даже если под ответами мало участников; всегда виден размер выборки. |
| 5. Разбор причины ошибки | Ученик указывает фрагмент, который подтверждает его выбор, или называет два варианта, между которыми сомневался. Преподаватель отличает слабое знание от невнимательного чтения. | Для одного Verbal-навыка после сдачи добавить второй короткий шаг «Покажи доказательство». Сохранить его рядом с ответом для закрытого разбора. | В разборе видны выбор и доказательство. Ученик проходит новую задачу на тот же приём, а преподаватель видит, перенёс ли он навык. |
| 6. Math с Desmos | После сдачи ученик может повторить проверку решения в Desmos и увидеть, как изменение коэффициента или точки меняет график. | Несколько авторских упражнений Data Analysis с готовой стартовой моделью и задачей изменить параметр. Модель для объяснения открывается после сдачи. | Ученик проходит «решил → проверил на графике → решил похожее» с телефона. Правильность оценивается по ответу, сохранённая работа в калькуляторе не влияет на балл. |
| 7. Урок из реальных ошибок | Преподаватель видит, какое ДЗ и какой навык дали больше всего ошибок, собирает короткий разбор и запускает его из пульта. | Черновик из трёх проверенных вопросов с основаниями выбора. Дальше добавить Gemini для гипотез о причинах ошибок и новых авторских задач, которые учитель просматривает перед показом. | От выбранной темы до черновика нужны максимум три действия. Для каждого пункта видно, что наблюдали в ответах и что остаётся предположением. |
| 8. Следующий холодный старт из прошлого урока | Преподаватель заканчивает занятие коротким заданием. На следующем уроке четыре вопроса проверяют, что сохранилось в памяти и может ли ученик применить приём в новом контексте. | Сформировать черновик из одной общей ошибки, одной задачи на перенос, одной темы для повторения и одной задачи по плану следующего урока. | Выбор каждого вопроса объясним в черновике. Учитель может заменить любой из четырёх, а прохождение измеряется отдельно от домашней работы. |
| 9. Персональная лестница подсказок | Ученик, которому нужна помощь, сначала получает направление для поиска доказательства, затем может обратиться к словарю или исключить два варианта. Готовые решать самостоятельно видят обычную задачу. | Использовать существующие разрешения преподавателя. Записывать, какая подсказка помогла, и давать одну парную задачу для самостоятельного решения. | Подсказки появляются только у учеников с назначенными разрешениями. Преподаватель видит результаты с поддержкой и самостоятельное решение. |
| 10. Итог урока за минуту | Преподаватель получает краткий срез по навыкам, проверяет рекомендации и выбирает следующий шаг для группы и отдельных учеников. | В сводке объединить урок и ДЗ по навыку, вывести число ответов, долю ошибок и одну проверяемую рекомендацию с переходом к исходным вопросам. | Учитель может открыть доказательство рекомендации из сводки. Неполные ответы, вопросы без ключа и заменённые версии тестов отражаются отдельно. |

## Как развивать идеи

После каждого изменения выбрать одно реальное неудобство и пройти соответствующий сценарий с преподавателем и двумя синтетическими учениками. Проверять телефон 320/390 px, клавиатуру и задержку сети там, где они меняют результат. Сравнивать время подготовки, число переходов между экранами, долю ответов с подтверждением и успешность решения новой задачи после разбора. Значения в таблице — условия будущей проверки. Базовые замеры сначала нужно получить.

Сначала выпустить устойчивое сохранение и целостный перенос задания, затем соединить пульт, живой раунд и разбор. Подсказки, рекомендации и новые задачи добавлять поверх уже надёжного потока ответов. В каждом цикле уточнять следующий сценарий, проверять ключевое предположение и записывать, что уже подтверждено и чего пока не знаем.
