## 0. Главное за минуту

- Курс: **16 уроков по 70 минут**. 11 уроков на общих навыках, 3 только IELTS, 2 на повторение и разбор.
- Общие навыки объясняются один раз. Потом показываем, как их проверяет каждый экзамен.
- **Честный минус:** в комбинированном уроке на навык SAT остаётся 20 минут вместо 70. Глубина SAT ниже, чем в текущем курсе.
- **Главное пересечение:** 11 из 16 уроков повторяют темы L01–L10. Для выпускников SAT-курса это дубль. Им нужен короткий мост, а не полный курс (вопрос 2).
- **Пробел в задании:** IELTS Listening не упомянут вообще. Это четверть общего балла IELTS (вопрос 4).
- **Риск для репутации:** подтверждённый Speaking у преподавателя 7.0. Нужно решить, до какого уровня курс честно готовит к Speaking (вопрос 5).

## 2. Карта навыков

**D** = переносится напрямую. **P** = частично. **N** = не переносится.

Сокращения: TR = Task Achievement / Task Response, CC = Coherence and Cohesion, LR = Lexical Resource, GRA = Grammatical Range and Accuracy, FC = Fluency and Coherence, Pron = Pronunciation.

### 2.1 Домены SAT против компонентов IELTS

| Домен SAT RW | Reading | W·TR | W·CC | W·LR | W·GRA | S·FC | S·LR | S·GRA | S·Pron |
|---|---|---|---|---|---|---|---|---|---|
| Information and Ideas | **D** | P | P | P | N | N | P | N | N |
| Craft and Structure | **D** | P | P | P | N | N | P | N | N |
| Expression of Ideas | P | P | **D** | P | P | P | N | N | N |
| Standard English Conventions | P | N | P | N | **D** | N | N | P | N |

Итог: **4 D, 16 P, 16 N** из 36 пар. Почти половина пар не переносится. Это нужно говорить честно.

### 2.2 Пояснения к парам

| Пара | Оценка | Почему |
|---|---|---|
| Information and Ideas → Reading | D | Главная мысль, деталь, вывод, доказательство. Те же операции. |
| Information and Ideas → W·TR | P | Quantitative evidence помогает читать график в Task 1. Писать обзор SAT не учит. |
| Craft and Structure → Reading | D | Слово в контексте = распознавание парафраза, основа IELTS Reading. |
| Craft and Structure → W·TR | P | Cross-Text даёт логику «две точки зрения» для Task 2. Только понимание, не письмо. |
| Craft and Structure → LR | P | SAT учит узнавать точное слово. IELTS требует его употребить. |
| Expression of Ideas → W·CC | D | Transitions = логические связки. Одно и то же знание. |
| Expression of Ideas → W·TR | P | Rhetorical Synthesis = отбор фактов под цель. Близко к Task 1. |
| Expression of Ideas → S·FC | P | Связки переносятся. Беглость нет. |
| Conventions → W·GRA | D | Границы предложений, согласование, времена, пунктуация. Оговорка: SAT проверяет выбор из четырёх, IELTS требует писать самому. |
| Conventions → S·GRA | P | Знание правила не даёт точности в живой речи. |
| Conventions → Reading | P | Помогает разбирать длинные предложения. |
| Любой домен → Pron | N | SAT не содержит звучащей речи. |

### 2.3 Пробелы

| Пробел | Сторона | Как закрываем |
|---|---|---|
| Нет говорения в SAT | IELTS | 10 минут в каждом уроке + урок C13 |
| Нет эссе в SAT | IELTS | микрозадание в каждом уроке + уроки C12 и C14 |
| Произношение | IELTS | 2 минуты внутри каждого speaking drill + половина C13 |
| **Listening** | IELTS | **в задании не указан.** Вариант: только домашняя работа (вопрос 4) |
| Длина текста: SAT 25–150 слов, IELTS около 700–900 `[FACT NEEDED: проверить по ielts.org]` | IELTS | выносливость тренируется дома на длинных текстах |
| True / False / Not Given | IELTS | отдельный блок в C07 и C09. В SAT аналога «Not Given» нет. |
| Орфография в ответах-вписываниях | IELTS | тест на слова печатью уже есть на сайте, принцип тот же |
| Архаика, поэзия, тонкая пунктуация | SAT | остаются в SAT-курсе, в общий курс не входят |
| SAT Math | SAT | вне курса |

## 3. Архитектура курса

### 3.1 Параметры

| Параметр | Значение |
|---|---|
| Уроков | 16 |
| Длина урока | 70 минут, не больше |
| Недель | 8 при двух уроках в неделю `[ПРЕДПОЛОЖЕНИЕ]`; 16 при одном |
| Общие навыки | C01–C11 |
| Только IELTS | C12, C13, C14 |
| Повторение и разбор | C15, C16 |
| Диагностика | до C01 и после C16 |

### 3.2 Последовательность

Логика: предложение → абзац → аргумент → полный формат. Поэтому порядок отличается от L01–L12.

| Урок | Общий навык | SAT (основа) | IELTS | Speaking drill | Writing micro-task |
|---|---|---|---|---|---|
| **Блок A. Предложение** | | | | | |
| C01 | Слово в контексте, парафраз | Words in Context (L01) | Reading: распознать парафраз | Part 1: короткие ответы | Paraphrase two sentences |
| C02 | Границы предложения | Boundaries (L02) | W·GRA: сложные предложения | Part 1: ответ + причина | Combine four short sentences |
| C03 | Форма и согласование | Form, Structure, and Sense (L03) | W·GRA: точность | Part 2: рассказ в прошедшем | Correct your own paragraph |
| C04 | Логические связки | Transitions (L05) | W·CC: cohesive devices | Part 3: мнение + связка | One paragraph, three links |
| **Блок B. Абзац** | | | | | |
| C05 | Отбор фактов под цель | Rhetorical Synthesis (L04) | Writing Task 1: overview | Describe a trend aloud | Write one overview sentence |
| C06 | Данные как доказательство | Command of Evidence, quantitative (L09) | Writing Task 1: сравнения | Compare two figures aloud | Two comparison sentences |
| C07 | Главная мысль и деталь | Central Ideas and Details (L08) | Reading: headings, T/F/NG | Part 2: структура ответа | Topic sentence for a paragraph |
| C08 | Структура и цель текста | Text Structure and Purpose (L06) | Reading: matching information · Task 2: абзац | Part 2: полный ответ, 2 минуты | One body paragraph |
| **Блок C. Аргумент** | | | | | |
| C09 | Вывод из текста | Inferences (L10) | Reading: Y/N/NG, summary | Part 3: объяснить причину | Claim + reason + example |
| C10 | Довод и поддержка | Command of Evidence, textual (L09) | Writing Task 2: W·TR | Part 3: довод и пример | Support one claim |
| C11 | Две точки зрения | Cross-Text Connections (L07) | Task 2: discuss both views | Part 3: сравнить взгляды | Introduction for a two-view essay |
| **Блок D. Только IELTS** | | | | | |
| C12 | — | — | Writing Task 2: план и эссе на время | Part 3 | эссе занимает основной блок |
| C13 | — | — | Speaking: все три части + произношение | весь урок | Self-review of the recording |
| C14 | — | — | Writing Task 1 полностью + разбор эссе C12 | Part 2 | Task 1 на время |
| **Блок E. Сборка** | | | | | |
| C15 | Смешанное повторение | формат L11 | Reading: три текста, тайминг | Part 1–3, короткий круг | Rewrite the weakest paragraph |
| C16 | Разбор диагностики | формат L12 | разбор обеих частей | Recorded final answer | Personal error list |

### 3.3 Где стоят навыки только IELTS

- **Speaking:** 10 минут в каждом уроке C01–C12 и C14–C16. Отдельный урок C13.
- **Writing Task 2:** строится по кирпичам. Предложение (C02–C04), абзац (C08), довод (C09–C11), полное эссе (C12).
- **Writing Task 1:** C05, C06, затем полностью в C14.
- **Произношение:** 2 минуты внутри каждого speaking drill, одна черта за урок (ударение в слове, ударение во фразе, паузы, интонация, связная речь). Половина C13.
- **Listening:** не размещён, ждёт ответа на вопрос 4.

### 3.4 Что курс не обещает

- Балл не обещается. После диагностики ученик получает реалистичный диапазон.
- SAT-часть мельче, чем в отдельном SAT-курсе. Цель по SAT выше `[FACT NEEDED: порог]` требует полного SAT-курса.
- Устойчивый рост Speaking и Writing требует практики между уроками. 10 минут в уроке этого не дают.

## 5. Общий словарь

### 5.1 Источники

| Источник | Объём | Статус |
|---|---|---|
| Трудные слова SAT Verbal | 580 слов, уже в колодах | готово, используем по ссылке |
| Academic Word List (Coxhead, 2000) | 570 семей слов, 10 подсписков `[FACT NEEDED: сверить с первоисточником]` | список открыт для чтения; условия коммерческого использования `[FACT NEEDED]` |

### 5.2 План

- На урок 10–12 слов: половина из колоды SAT, половина из AWL.
- За 16 уроков в классе проходит около 160–190 слов. Весь AWL в уроки не помещается. Остальное идёт колодами для самостоятельной работы, по подспискам 1–10.
- Сначала слова, которые есть в обоих списках (после подсчёта П5). Они дают двойную отдачу.
- Подбор под навык урока: в C04 связки и слова логики, в C05–C06 слова о данных и изменениях.
- Проверка та же, что в SAT-курсе: карточки, затем печатный тест накануне следующего урока.

### 5.3 Формат карточки

Каждое слово получает два оригинальных примера: один в стиле SAT, один в стиле IELTS.

| Поле | Содержание |
|---|---|
| Word | слово и часть речи |
| Meaning | короткое определение на английском |
| Перевод | 1–2 русских эквивалента |
| SAT-style sentence | плотное академическое предложение, как в тексте SAT |
| IELTS-style sentence | предложение для эссе или устного ответа |
| Source | SAT deck / AWL sublist N / both |

Образец формата (один, не материал урока):

| Word | SAT-style sentence | IELTS-style sentence |
|---|---|---|
| constrain (v.) | The survey's small sample constrains how far its conclusions can be generalized. | Limited public funding often constrains what local schools are able to offer. |

Все примеры пишутся с нуля. Предложения из официальных материалов и словарей не копируются.

## 6. Диагностика

Цель: два диапазона (SAT RW и IELTS) и список слабых навыков. Не балл.

### 6.1 Часть SAT RW

| Параметр | Значение |
|---|---|
| Набор | RW-часть PT1 (уже на сайте, уже стартовая точка SAT-курса) |
| Формат | 2 модуля по 27 вопросов, 64 минуты, адаптивно |
| Результат | «примерный балл» из `scale.js`, показывается как диапазон ±40 |
| Слабые навыки | до 4, уже считает сайт |

Новых вопросов не нужно. Короткая альтернатива на 22 вопроса и 26 минут (6 Information and Ideas, 6 Craft and Structure, 6 Conventions, 4 Expression of Ideas) потребует новых оригинальных вопросов и даст более грубый диапазон.

### 6.2 Часть в стиле IELTS

Называется «IELTS-style». Не официальный тест и не его копия.

| Компонент | Формат | Время | Как оценивается |
|---|---|---|---|
| Reading | 1 оригинальный текст около 800 слов, 13 вопросов трёх типов | 20 мин | сырой балл → диапазон шириной в одну полосу |
| Writing | 1 оригинальное задание Task 2 | 40 мин | преподаватель по публичным критериям, диапазон в одну полосу |
| Speaking | запись: Part 1 (2 мин) + Part 2 (2 мин) | 5 мин | преподаватель по публичным критериям, диапазон в одну полосу |
| Listening | нет | — | ждёт вопроса 4 |

- 13 вопросов не различают половину полосы. Поэтому только диапазон.
- Таблицы перевода сырого балла в полосу своей нет. `[FACT NEEDED: какую публичную ориентировочную таблицу использовать и можно ли на неё ссылаться]`
- Формулировка для ученика: “Your likely range today is 6.0–7.0. This is an estimate, not a result.”

### 6.3 Нагрузка

Полная диагностика занимает около 130 минут. Это не помещается в бесплатную консультацию на 20 минут. Ученик делает её дома, на консультации идёт разбор (вопрос 8).

## 7. Открытые вопросы для преподавателя

1. **Для кого курс?** Новые ученики, которым нужны оба экзамена? Или выпускники SAT-курса тоже?
2. **Нужен ли мост «IELTS после SAT»** на 6–8 уроков для тех, кто уже прошёл L01–L12?
3. **Темп:** два урока в неделю (8 недель) или один (16 недель)?
4. **Listening:** включаем? Если да, то в урок (тогда нужно убрать что-то из шаблона) или только домашней работой?
5. **Speaking:** твой подтверждённый балл 7.0. До какого целевого уровня ученика курс честно берётся готовить? Нужен ли приглашённый проверяющий для высоких целей?
6. **IELTS Writing возвращается?** В `CLAUDE.md` сейчас записано, что он не предлагается.
7. **Проверка письма и записей:** сколько эссе и записей в неделю ты готов проверять при лимите 20–24 часа? При группе из 6 это около 12 работ в неделю.
8. **Диагностика:** ученик делает её дома до консультации? RW-часть PT1 подходит как SAT-половина?
9. **Место на сайте:** новый верхний раздел или карточка в «Полезное» по действующему правилу?
10. **Запуск:** после окончания текущего SAT-курса или параллельно, только для новых учеников?
11. **Формат IELTS:** Academic на компьютере? Нужен ли General Training?
12. **AWL:** можно ли подтвердить условия использования списка в платных материалах? Если нет, берём только слова, без структуры подсписков.
13. **«Курс 2.0 · метанавыки»:** он идёт раньше, позже или вместе с этим курсом? Оба меняют шаблон урока.
14. **Запись речи:** чем ученики записывают ответы и где хранятся записи? Для учеников младше 18 нужно согласие родителя.
15. **Цена и размер группы:** та же сетка (индивидуально, дуэт, группа из 6) или другая? В документе цен нет.
16. **Этот документ:** оставить только в чате или положить в репозиторий в зашифрованном виде, как `notes/private/`?
