# Student weak spots · SAT + IELTS

11 Nov 2026 · copy of the private doc https://claude.ai/artifact/LuHP53NRiu7Xm4uNHTY1r4 (the doc is the working version; Nurassyl fills the homework column there)

## How to use this

Nine categories of weak spots your students are likely to have, with the signs to look for and where each one shows up. The last column of every table is empty: that is where you write the homework you assign.

These are typical weak spots for Russian- and Kazakh-speaking students in grades 9–12 preparing for the SAT Reading and Writing and IELTS Academic. They are not measured for your students yet. Confirm each one with a student's diagnostic, homework or office hours before you assign anything.

**Where it shows** uses these sources from the course site:

- **Skills table:** first-attempt accuracy by skill on the Progress page.
- **Check-ins:** the diagnostic compared with each block check-in, skill by skill.
- **Mistake tags:** the mistake types students pick in office hours (Russian on the site, quoted in English here).
- **Writing numbers:** word count, linking words and lesson words used, on the Progress page.
- **Peer review:** how many planted problems a student found in the sample answer.
- **Live only:** visible only when you hear or watch the student in office hours.

## A. Vocabulary and meaning

The biggest single area for both exams: SAT Words in Context and IELTS paraphrase both depend on knowing what a word means in this sentence.

| Weak spot | How it shows | Where it shows | Homework (you assign) |
| --- | --- | --- | --- |
| Too few academic words | Stops on words like *undermine*, *tentative*, *substantial*; guesses from the topic | Skills table: Words in Context; mistake tag “wrong meaning of the word” | |
| Familiar word, unusual meaning | Picks the common meaning: *render* = provide, *novel* = book, *qualify* = be eligible | Mistake tag “wrong meaning of the word” on “most nearly mean” questions | |
| False friends from Russian | *actual* read as актуальный, *sympathetic* as симпатичный, *accurate* as аккуратный | Live only; sometimes Words in Context misses | |
| Weak collocations | *make a research*, *do a mistake*, *big attention* in writing and speech | Peer review (LR); live only | |
| Wrong word form | *significance* where *significant* is needed; *economic* vs *economical* | Writing numbers; Form, Structure, and Sense misses | |
| Missing paraphrase sense | Looks for the same words in the text; misses the same idea said differently | IELTS True / False / Not Given misses; Listening misses | |
| Register | Informal words in essays: *a lot of*, *kids*, *stuff*, *old people* | Peer review (LR) | |

## B. Grammar and sentence boundaries

Most of these come from transferring Russian or Kazakh habits into English. They cost points on SAT Conventions and on IELTS Grammatical Range and Accuracy.

| Weak spot | How it shows | Where it shows | Homework (you assign) |
| --- | --- | --- | --- |
| Articles | Missing or wrong *a / the* (neither Russian nor Kazakh has articles) | Peer review (GRA); live only | |
| Comma habits from Russian | Comma splices; a comma before every *that* or *which*; long sentences joined by commas | Skills table: Boundaries | |
| Agreement across a long subject | *The records kept by the keeper is*…: the verb matches the nearest noun | Skills table: Form, Structure, and Sense | |
| Tenses and aspect | Present perfect vs past simple; *since 2020 I study*; tense shifts inside a paragraph | Form, Structure, and Sense; peer review (GRA) | |
| Prepositions | *depend from*, *discuss about*, *in the internet* | Peer review (GRA); live only | |
| Pronouns and possessives | *its / it's*, *their* for a singular noun, unclear *this* | Form, Structure, and Sense | |
| Colons, semicolons, dashes | Uses them for style, not by rule | Skills table: Boundaries | |
| Fragments and run-ons in writing | *Because the data shows…* as a full sentence; one sentence across five lines | Peer review (GRA) | |

## C. Reading and reasoning

Strong readers lose points here by reading well but answering loosely. These weak spots hit both exams at once.

| Weak spot | How it shows | Where it shows | Homework (you assign) |
| --- | --- | --- | --- |
| Using outside knowledge | Answers from what they know, not what the text says; marks FALSE where the answer is NOT GIVEN | Check-ins and skills table: True / False / Not Given; mistake tag “answer not from the text” | |
| Detail mistaken for the main idea | Picks a true but narrow statement | Skills table: Central Ideas and Details | |
| Over-inference | Picks the boldest choice; reads more into the text than it supports | Inference misses; mistake tag “answer not from the text” | |
| Ignoring scope words | Misses *only*, *always*, *some*, *most*, *not* | True / False / Not Given misses | |
| True but off-goal | Picks a correct fact that does not do what the question asks | Skills table: Rhetorical Synthesis; mistake tag “fact right, goal wrong” | |
| Reading tables and graphs | Swaps rows or columns, “before” and “after”, counts and percentages | Skills table: Command of Evidence (quantitative); mistake tag “mixed up the data” | |
| Relationship between ideas | Treats a result as a contrast; misreads *nevertheless*, *whereas* | Skills table: Transitions; mistake tag “wrong relationship” | |
| Old and literary texts | Slows down or gets lost in 19th-century prose and poetry | SAT lesson A and the archaic sets; live only | |
| Long-text stamina | Accuracy drops in the third IELTS passage | Live only; a timed full reading test | |

## D. Exam strategy and timing

These weak spots are about how a student takes the test, not what they know. A student who knows enough English can still lose points here.

| Weak spot | How it shows | Where it shows | Homework (you assign) |
| --- | --- | --- | --- |
| No prediction before the choices | Reads all four options first and gets pulled by the most attractive one | Many mistakes tagged “fact right, goal wrong” or “wrong relationship” | |
| Running out of time | Rushes or guesses the last questions of a module or passage | Live only; timed mock tests | |
| Spending too long on one question | Fights one hard item instead of moving on and coming back | Live only; timed mock tests | |
| Changing right answers | Second-guesses a correct first choice | Live only; ask in office hours | |
| Careless reading | Misreads the question or the stem: *NOT*, *EXCEPT*, *which choice best supports* | Mistake tag “read carelessly” | |
| IELTS answer rules | Breaks word limits (“NO MORE THAN TWO WORDS”), misspells, drops plural *-s* | Live only; IELTS-style answer sheet | |
| No error review | Repeats the same mistake type across lessons | Same mistake tag in several lessons; low “fixed on retry” count | |

## E. IELTS Writing

The SAT has no essay, so even strong SAT students often arrive with no habit of writing in English under time.

| Weak spot | How it shows | Where it shows | Homework (you assign) |
| --- | --- | --- | --- |
| No overview in Task 1 | Lists every number; never states the main trend | Peer review (TR); writing micro-task in C05 | |
| Explaining causes in Task 1 | Adds reasons the chart does not show | Peer review (TR) | |
| Unclear position in Task 2 | The reader cannot tell what the student thinks until the end, or at all | Peer review (TR); live only | |
| Ideas without support | Claims with no reason or example; very general statements | Peer review (TR) | |
| Memorised templates | *In this modern era…*, *It is a double-edged sword* | Peer review (LR); live only | |
| Linking words overused or wrong | *Moreover* at the start of every sentence; *however* where a result is meant | Writing numbers (links); peer review (CC) | |
| Paragraphing | One block of text; or a new paragraph for every sentence | Peer review (CC) | |
| Word count and time | Under 150 / 250 words; Task 1 eats Task 2's time | Writing numbers (words); live only | |

## F. IELTS Speaking and pronunciation

Almost all of this shows only when you hear the student live, so office hours are the main place to spot it.

| Weak spot | How it shows | Where it shows | Homework (you assign) |
| --- | --- | --- | --- |
| Answers too short | One-sentence answers in Part 1; no reason or example | Live only | |
| Running out in Part 2 | Stops after 40–60 seconds of the two minutes | Live only; speaking timer at home | |
| Abstract ideas in Part 3 | Retells personal stories instead of discussing society, causes and effects | Live only | |
| Long pauses, translating in the head | Builds the sentence in Russian first; stops mid-sentence | Live only | |
| Word stress | *de-VE-lop* said as *DE-ve-lop*; *-teen* and *-ty* numbers mixed up | Live only; pronunciation focus in each lesson | |
| Sounds | *th* as *s / z*, *w* as *v*, short and long vowels (*ship / sheep*), dropped final consonants | Live only | |
| Flat intonation | No rise and fall; every sentence sounds like a list | Live only | |
| Memorised answers | Fluent prepared text that does not fit the question | Live only | |
| Grammar breaks under pressure | Tenses and articles that are correct in writing fall apart when speaking | Live only | |

## G. IELTS Listening

The SAT has no listening at all, so this is new for most students, however good their reading is.

| Weak spot | How it shows | Where it shows | Homework (you assign) |
| --- | --- | --- | --- |
| Falling for the first answer | Writes what is said first, before the speaker corrects it (*used to be*, *actually*, *instead*) | Skills table: IELTS Listening; C12 | |
| No prediction before the audio | Does not decide whether the gap needs a number, a name or a place | C12 answer-type questions | |
| Spelling names and numbers | Mishears spelled-out names, double letters, *13 / 30* | Live only; dictation | |
| Losing the place | Misses one answer, then the next three | Live only | |
| Unfamiliar accents | Follows a teacher's accent but not British or Australian speakers | Live only | |
| Maps and directions | Mixes up left and right, or forgets which way the speaker is facing | C12 map questions | |

## H. Study habits and mindset

These decide whether homework turns into progress. Many are visible in the site's data before the student mentions them.

| Weak spot | How it shows | Where it shows | Homework (you assign) |
| --- | --- | --- | --- |
| Rereading instead of recall | Reviews words by reading the list; forgets them a week later | Low scores on the evening word test; recall slide at the start of class | |
| Irregular homework | Does everything the night before class, or skips steps | Four-step grid on the Progress page: gaps in steps 2–4 | |
| Skipping the retry | Never redoes missed questions after office hours | Four-step grid: step 4 open; low “fixed on retry” count | |
| Overconfidence | Strong general English, so skips strategy and loses easy points | High skills table, but many mistakes tagged “read carelessly” | |
| Perfectionism and test anxiety | Slows down on hard items; blanks under time | Live only; timed mocks | |
| No English outside class | No reading or listening in English between lessons | Live only; ask in office hours | |
| Leaning on translators or AI | Writing that sounds much better than the student speaks | Peer review compared with live speaking | |
| School load | Work drops before school exams and olympiads | Four-step grid over time | |

## I. Background knowledge

Both exams say no outside knowledge is needed, but unfamiliar contexts slow students down and raise doubt.

| Weak spot | How it shows | Where it shows | Homework (you assign) |
| --- | --- | --- | --- |
| US and UK history and society | Slows down on texts about American institutions, British history or civil rights | Live only; timing on those passages | |
| Science and research language | Gets lost in *hypothesis*, *sample*, *control group*, *findings suggest* | Skills table: Command of Evidence (textual); Inferences | |
| Data literacy | Confuses percent with percentage points; rate with total | Skills table: Command of Evidence (quantitative) | |
| Literary conventions | Misses irony, a narrator's attitude, or tone in fiction and poetry | Text Structure and Purpose misses; SAT lesson A | |
| Essay topics | Has little to say on common IELTS themes: technology, environment, education, work | Live only; Task 2 planning | |
